# Contributing

Contributions are welcome. Please keep changes focused and aligned with the project's existing conventions.

## Development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make the change and add or update relevant tests.
4. Run `npm run lint:check` and `npm run type-check`.
5. Open a pull request with a clear description of the change.

## Pull Requests

- Explain the problem and the proposed solution.
- Include relevant examples or test coverage.
- Keep unrelated refactoring out of the pull request.
- Confirm that formatting, linting, and type checks pass.
