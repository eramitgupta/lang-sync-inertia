# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of the package.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Please contact the repository maintainer through the [GitHub profile](https://github.com/eramitgupta) and include:

- A description of the vulnerability
- Affected versions
- Reproduction steps or a proof of concept
- Any suggested mitigation or fix

The maintainers will review the report and respond with next steps. Please allow reasonable time for investigation and a fix before publicly disclosing the issue.
